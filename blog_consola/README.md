# Sistema de Blog por Consola

Este proyecto es un sistema de gestión de posts de blog ejecutado a través de la consola. Permite a los usuarios listar artículos, buscar por título, filtrar por etiquetas y validar la estructura de los datos cargados en memoria. 

El propósito principal es demostrar la separación de responsabilidades y la modularización en Python creando paquetes, importaciones relativas y organización de código escalable.

## Cómo ejecutar el sistema

1. Asegúrate de tener Python 3.14,2 instalado en tu sistema.
2. Abre una terminal y navega hasta el directorio raíz del proyecto (`blog_consola`).
3. Ejecuta el archivo principal utilizando el siguiente comando:

   ```bash
   python main.py
